# ToDo API

Учебный API для управления задачами по матрице Эйзенхауэра.
FastAPI, SQLAlchemy, PostgreSQL (Supabase). Версия 2.0.0.

Поддерживает создание, изменение, завершение и удаление задач, поиск и статистику. Срочность определяется по дедлайну: не больше 3 дней — срочно.

## Запуск

В Git Bash:

```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
```

В `.env` укажите `DATABASE_URL` — строку подключения к Supabase с префиксом `postgresql+asyncpg://`. Файл исключён из Git.

```bash
python test_connection.py
uvicorn main:app --reload
```

При обновлении существующей БД колонка `deadline_at DATE` должна быть добавлена заранее.

## Проверка

Swagger: http://127.0.0.1:8000/docs

- `/api/v2/tasks` — задачи.
- `/api/v2/tasks/today` — задачи с дедлайном сегодня.
- `/api/v2/stats/` — статистика.
- `/api/v2/stats/deadlines` — сроки незавершённых задач.
- `/api/v2/stats/timing` — количество завершённых вовремя, с опозданием, выполняемых по плану и просроченных задач.
- `/health` — проверка подключения к БД.

В POST можно передать `deadline_at` в формате `YYYY-MM-DD` или создать задачу без срока. В PUT значение `null` убирает дедлайн. Ответ содержит оставшиеся дни (`days_remaining` и `days_until_deadline`), срочность, квадрант и `status_message`.

Сроки считаются по московским календарным дням. Сегодня — ещё в срок; задачи без дедлайна не входят в четыре счётчика `/timing`. Для завершённых задач также нужна дата завершения.

Планировщик обновляет `is_urgent` и `quadrant` незавершённых задач в БД при запуске приложения и каждый день в 09:00 по Москве. Завершённые задачи он не меняет. Ответы API и SQL-статистика рассчитываются на текущую дату.
